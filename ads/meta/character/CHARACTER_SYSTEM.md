# GRW Animated Character System — Meta (v1)

**Funnel:** Meta ad → GRW guide (`/research/bpc-157`) → disclosed Swiss Chems CTA on-page  
**Not:** Direct-to-Swiss cold traffic (that kit stays in `ads/meta/ad-copy.md` as a separate lane)

---

## Character: “Atlas”

**Role:** Calm research guide — not a doctor, coach, or salesperson.  
**Job in ads:** Ask better questions, point at evidence limits, hand off to the free guide.

### Design (lock this look)

| Element | Spec |
|--------|------|
| Style | **Almost-real editorial human** — photoreal-adjacent face/fabric; still a branded character, not random UGC |
| References | `ads/meta/character/reference/atlas-primary.png` (reading book — locked) |
| Production | AI video with image reference lock — see `ALMOST_REAL_BRIEF.md` |
| Body | Adult proportions; navy research coat, light shirt — **not** white medical coat |
| Face | Thin metal glasses, short dark hair, calm neutral expression |
| Hands | Notebook / checklist props only — never a vial/syringe |
| Palette | Ink `#0F172A`, navy coat, soft key light, cool rim |
| Motion | Slow, deliberate; 1 gesture per beat; no bounce memes, no dance trends |

**Realism ladder**
1. Geometric / flat illustrated — retired for this lane  
2. Semi-real illustrated boards — optional stills only  
3. **Almost-real (current)** — reference images + AI video motion  
4. Full UGC — real person on camera (backup if AI gets restricted)

### Personality rules

- Speaks in short on-screen titles (voice optional later)
- Never says “heal,” “cure,” “fixed my,” “guaranteed”
- Never holds product packaging or points at a Buy button
- End frame always: **GRW Research** + guide URL path

### Do / don’t

**Do:** notebook, checklist, papers, simple molecule glyphs, reading glasses pause  
**Don’t:** before/after bodies, glowing joints, gym transforms, “doctor” white coat authority cosplay, Swiss Chems logo in the ad

## 15s story spine (all character ads)

```
0–3s   Hook (Atlas + one provocative research question)
3–8s   Insight (one idea only)
8–12s  Proof gesture (checklist / limit / open question)
12–15s Hand-off to GRW guide CTA
```

Destination for Ads Manager (all character creatives):

```
https://www.grwresearch.com/research/bpc-157?utm_source=meta&utm_medium=paid&utm_campaign=swiss_bpc_atlas_v1&utm_content=CREATIVE_ID
```

Swiss appears **only on the guide page**, after education.

## Three storyboards

### A — `atlas_what_is_bpc` (overview)

| Time | Visual | On-screen text |
|------|--------|----------------|
| 0–3s | Atlas looks at floating claim bubbles (“miracle,” “fixed overnight”) and shakes head once | Before you trust online peptide claims |
| 3–8s | Bubbles dissolve; notebook opens to “BPC-157” title page | What the research discussion actually covers |
| 8–12s | Atlas underlines “limits” and “open questions” | Evidence. Limits. Context. |
| 12–15s | Atlas points to GRW lockup; soft accent bar | Free research guide → grwresearch.com |

### B — `atlas_coa_checklist` (quality)

| Time | Visual | On-screen text |
|------|--------|----------------|
| 0–3s | Atlas with blank checklist clipboard | How researchers evaluate quality docs |
| 3–8s | Checks appear: testing transparency, labeling, research-use notice | Three things to look for |
| 8–12s | Clipboard becomes a calm “ready to read” state — still no product | Ask better questions first |
| 12–15s | Guide CTA | Read the BPC-157 guide |

### C — `atlas_evidence_limits` (trust)

| Time | Visual | On-screen text |
|------|--------|----------------|
| 0–3s | Split: loud claim vs quiet paper stack | Most claims outrun the evidence |
| 3–8s | Atlas draws ≠ between “mechanism talk” and “human outcomes” | Mechanisms ≠ proven outcomes |
| 8–12s | Soft dim on hype side; paper side stays lit | Stay cautious. Stay literate. |
| 12–15s | Guide CTA | Independent guide from GRW Research |

## Production path (phased)

### Phase 1 — Concept lock (this folder)
- Character sheet (front / 3/4 / gesture)
- 3 storyboards as still frames
- Ad copy + destinations

### Phase 2 — Motion prototype
- Animate Atlas in-repo (frame script) **or** Remotion / After Effects
- 1080×1920, 15s, 30fps
- No voice first; captions only (safer + faster)

### Phase 3 — Polish
- Optional soft VO (neutral, educational)
- Loop-safe first 1s for Reels thumbs

**Not starting with:** hyper-real AI influencers, UGC “bro,” product unboxings.

---

## Success criteria for v1 character ads

- Viewer understands GRW is a **guide**, not a store
- Click lands on `/research/bpc-157`
- Swiss CTA only after scroll/education on-page
- No medical-result imagery
